**Firewalls**	Act as barriers between trusted internal networks and untrusted external networks, filtering traffic based on predetermined security rules.

**Intrusion Detection and Prevention Systems (IDS/IPS)**	Monitor network traffic for suspicious activities and take automated actions to detect or block potential threats.

**Virtual Private Networks (VPNs)**	Provide secure, encrypted connections over public networks, ensuring data privacy and integrity during transmission. For example, used by employees to connect to internal network resources.

**Access control mechanisms**	Include authentication and authorization protocols to ensure only legitimate users can access network resources.

**Encryption technologies**	Protect sensitive data both in transit and at rest, rendering it unreadable to unauthorized parties.

## Network Security — Responsibility
- Primary responsibility: IT department, specifically the Network Security Team.
- Network Security Manager: Leads the team and typically reports to the CISO (Chief Information Security Officer).
### 1. Network Security Team Responsibilities
- Design, implement, and maintain network security infrastructure.
- Configure and manage security devices.
- Develop and enforce security policies.
- Monitor network traffic for potential threats.
- Respond to security incidents.
### 2. Testing Network Security
- Penetration testers / Ethical hackers: Simulate real-world attacks to identify vulnerabilities and weaknesses.
- Purpose: Evaluate security effectiveness, understand the organization's security posture, and prioritize improvements.
- Who performs testing?
    - Large organizations: Internal security teams.
    - Small organizations: External security consultants or Managed Security Service Providers (MSSPs).

### 3. Key Stakeholders

|Role|Primary Responsibility|
|---|---|
|CISO|Defines security strategy and aligns security with business goals and risk tolerance.|
|CIO / IT Director|Allocates resources and integrates security into IT infrastructure.|
|Network Administrators|Manage and maintain network operations.|
|Security Analysts|Monitor networks, investigate threats, and support incident response.|
|Compliance Officers|Ensure security meets regulatory requirements.|
|Risk Management Teams|Assess business risks and prioritize security investments.|

### 4. Key Takeaways
- Network security is a shared responsibility across multiple departments and roles.
- Security requires continuous monitoring, testing, and improvement.
- Security assessments help identify weaknesses before attackers exploit them.
- Network security protects an organization's digital assets against cyber threats.

Remember: The CISO sets the strategy, the network security team implements and maintains defenses, and penetration testers evaluate those defenses.
