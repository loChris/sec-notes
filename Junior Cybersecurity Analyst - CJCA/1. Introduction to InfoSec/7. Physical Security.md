### 1. Definition
Physical Security is the protection of people, facilities, hardware, and physical information assets from unauthorized access, theft, damage, and disruption.

Protected assets include computers, servers, network equipment, server racks, and printed documents.
### 2. Goals of Physical Security
Physical security uses multiple layers of protection, known as Defense in Depth, so that if one security measure fails, others remain in place.

Its four primary objectives are:
- Deter: Discourage potential attackers (e.g., fencing, visible security cameras).
- Detect: Identify unauthorized activity (e.g., alarms, surveillance).
- Delay: Slow an intruder's progress (e.g., reinforced doors, barriers).
- Respond: Take action when a threat or breach occurs (e.g., security personnel responding to alarms).
### 3. Key Physical Security Measures
- Perimeter Security: Fences, barriers, gates, and controlled entry points.
- Access Control: Locks, access cards, biometric authentication, and entry permissions.
- Surveillance: Security cameras and monitoring systems.
- Environmental Controls: Systems such as fire detection, temperature regulation, and water-leak detection to protect people and equipment.
- Personnel Security: Security procedures for employees, visitors, and contractors.
- Visitor Management: Identifying, authorizing, escorting, and monitoring visitors.
### 4. Why Physical Security Matters
- Protects equipment and data-bearing devices from theft or damage.
- Safeguards employees and visitors.
- Prevents operational disruptions caused by physical incidents.
- Supports regulatory and compliance requirements.
- Protects the confidentiality, integrity, and availability (CIA triad) of information.
### 5. Responsibilities

| Role                   | Responsibility                                                                                         |
| ---------------------- | ------------------------------------------------------------------------------------------------------ |
| Physical Security Team | Manages physical protection measures and responds to physical security threats.                        |
| CSO / CISO             | Oversees physical security or coordinates it with information security, depending on the organization. |
| Facilities Management  | Maintains buildings, doors, locks, environmental systems, and other physical controls.                 |
| IT Security Team       | Protects IT equipment and coordinates physical safeguards for technology infrastructure.               |
| All Employees          | Follow security procedures, protect credentials, and report suspicious activity.                       |
### 6. Physical Security Testing
Physical penetration testers / Red Teamers conduct authorized assessments to determine whether physical security controls can be bypassed.

Common vulnerabilities include:

| Vulnerability                 | Description                                                                      |
| ----------------------------- | -------------------------------------------------------------------------------- |
| Unsecured Access Points       | Unlocked or poorly secured doors and windows.                                    |
| Weak Locks                    | Locks that provide inadequate protection.                                        |
| Inadequate Perimeter Security | Insufficient fencing, barriers, or surveillance.                                 |
| Poor Key Management           | Improper handling of keys or access cards.                                       |
| Insufficient Lighting         | Poorly illuminated areas that reduce visibility.                                 |
| Exposed IT Infrastructure     | Servers, network equipment, or wiring closets accessible to unauthorized people. |
| Weak Visitor Management       | Inadequate visitor identification, authorization, or monitoring.                 |
| Unattended Workstations       | Unlocked computers accessible to unauthorized individuals.                       |
Testing may include evaluating access controls, surveillance coverage, physical barriers, security personnel response, and employee resistance to social engineering.
### 7. Relationship to Cybersecurity
Physical access can undermine digital security. For example, someone who gains unauthorized access to a server room or an unattended computer may be able to bypass protections that would otherwise defend the system remotely.

Therefore, physical security must complement technical cybersecurity controls.
### Key Takeaways
- Physical security protects people, facilities, hardware, and physical data.
- Defense in Depth uses multiple layers to deter, detect, delay, and respond to threats.
- Physical security is a shared responsibility involving security teams, facilities, IT, and employees.
- Red Teamers assess physical defenses and identify weaknesses.
- Strong physical security is essential to protecting the confidentiality, integrity, and availability of information.

Remember: Cybersecurity protects digital systems; physical security protects the physical assets and environments those systems depend on. Both are necessary for comprehensive information security.
