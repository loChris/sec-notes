## What is Network Security?

Network security involves protecting network data, devices, applications, and systems from unauthorized access or damage. Its goal is to maintain the CIA triad:

- Confidentiality: Only authorized users can access data.
- Integrity: Data remains accurate and unaltered.
- Availability: Resources remain accessible when needed.

## Firewalls

A firewall monitors incoming and outgoing network traffic and allows or blocks it based on predefined rules. It can filter traffic using IP addresses, port numbers, and protocols, as well as log events and generate alerts.

### Types of Firewalls

- Packet Filtering Firewall: Filters packets based on IP addresses, ports, and protocols. Operates at OSI Layers 3 and 4.
- Stateful Inspection Firewall: Tracks connection states and allows traffic that belongs to established connections.
- Application Layer (Proxy) Firewall: Inspects application-level traffic, such as HTTP requests, to identify malicious content.
- Next-Generation Firewall (NGFW): Combines stateful inspection with advanced features such as deep packet inspection, IDS/IPS, and application control.

Firewalls may be built into home routers or deployed as separate devices in business networks.

## Intrusion Detection and Prevention Systems (IDS/IPS)

IDS and IPS monitor network traffic or system activity for suspicious behavior.

- IDS (Intrusion Detection System): Detects suspicious activity and generates alerts but does not block the traffic.
- IPS (Intrusion Prevention System): Detects suspicious activity and can block or reject malicious traffic in real time.

### Detection Techniques

- Signature-Based Detection: Compares activity against known attack signatures.
- Anomaly-Based Detection: Identifies activity that differs from normal behavior.

### Types of IDS/IPS

- Network-Based (NIDS/NIPS): Monitors traffic passing through strategic points in a network.
- Host-Based (HIDS/HIPS): Monitors activity, traffic, and logs on individual devices.

IDS/IPS can be placed behind a firewall, in a DMZ, or directly on endpoints such as servers and workstations.

## Network Security Best Practices

- Define Clear Policies: Apply the principle of least privilege, allowing only necessary access.
- Regular Updates: Keep operating systems, firewalls, and IDS/IPS signatures updated.
- Monitor and Log Events: Review logs and alerts to identify suspicious activity.
- Layered Security: Combine firewalls, IDS/IPS, antivirus, and endpoint protection.
- Periodic Penetration Testing: Simulate attacks to evaluate security controls and policies.

## Key Takeaway

Firewalls control which traffic is allowed through a network, while IDS detects suspicious activity and IPS detects and blocks it. Combining these tools with monitoring, updates, least-privilege policies, and layered defenses helps strengthen network security.
