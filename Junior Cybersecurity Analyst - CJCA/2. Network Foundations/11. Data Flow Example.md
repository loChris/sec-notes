# 1. Connecting to the Internet

- The laptop identifies the correct Wi-Fi network (SSID).
- WPA2/WPA3 networks require authentication.
- Once connected, DHCP handles IP configuration.

## 2. DHCP Configuration

- The laptop requests an IP address from the router's DHCP server if it doesn't already have one.
- DHCP assigns a private IP address and provides the subnet mask, default gateway, and DNS server.

## 3. DNS Resolution

- The laptop sends a DNS query to find the IP address associated with `www.example.com`.
- The DNS server returns the website's IP address.

## 4. Data Encapsulation and Transmission

The browser's request passes through the network layers:

- Application Layer: Creates an HTTP/HTTPS request.
- Transport Layer: Adds a TCP segment with source and destination ports.
- Internet Layer: Adds an IP header containing source and destination IP addresses.
- Link Layer: Adds a frame containing MAC addresses.

The laptop uses ARP to find the router's MAC address, then sends the frame to the router.

## 5. Network Address Translation (NAT)

- The router replaces the laptop's private source IP with its public IP.
- The packet travels through the ISP's network and intermediate routers until it reaches the destination server.

## 6. Server Receives and Responds

- The server's firewall checks whether the incoming traffic is allowed.
- The web server processes the request and sends the webpage back.
- The response travels back through the internet to the home router.
- NAT maps the response back to the laptop's private IP address.

## 7. Decapsulation and Display

- The laptop removes the network headers and frame information to extract the application data.
- The browser processes the HTML, CSS, and JavaScript and displays the webpage.

## Key Takeaway

Accessing a website involves several networking processes working together: Wi-Fi authentication, DHCP, DNS, encapsulation, ARP, NAT, routing, and decapsulation. These allow a laptop to locate a server, send a request, receive a response, and display the webpage.
