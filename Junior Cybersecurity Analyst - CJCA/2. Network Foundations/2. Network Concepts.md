## 1. OSI Model

The Open Systems Interconnection (OSI) model is a conceptual framework that divides network communication into seven layers. It helps explain how data travels across networks and supports interoperability between devices and software.

|Layer|Name|Main Function|Examples|
|---|---|---|---|
|7|Application|Provides network services to applications.|HTTP, FTP, SMTP, DNS|
|6|Presentation|Handles data formats, encryption/decryption, and compression.|Data encoding, encryption|
|5|Session|Establishes, maintains, and terminates communication sessions.|Session management|
|4|Transport|Provides end-to-end delivery, segmentation, and error checking.|TCP, UDP|
|3|Network|Handles logical addressing and routing between networks.|IP, routers|
|2|Data Link|Transfers frames between directly connected nodes; uses MAC addresses.|Switches, bridges|
|1|Physical|Transmits raw bits over physical media.|Ethernet cables, hubs, repeaters|

Sending data: Data moves down the layers on the sender's device, travels across the network, and moves up the layers on the receiving device.

## 2. TCP/IP Model

The TCP/IP model is a practical, four-layer model used for communication across the Internet and other networks.

|TCP/IP Layer|Main Function|Equivalent OSI Layers|
|---|---|---|
|Application|Provides services such as web browsing, file transfers, and email.|7, 6, 5|
|Transport|Handles end-to-end communication using TCP or UDP.|4|
|Internet|Handles IP addressing and packet routing.|3|
|Link|Handles physical connections and data framing.|2, 1|

### OSI vs. TCP/IP

- OSI: Seven-layer conceptual model used to understand and troubleshoot networking.
- TCP/IP: Four-layer model designed around practical network communication and Internet protocols.

## 3. Common Network Protocols

A protocol is a standardized set of rules governing how devices format, send, receive, and process data.

|Protocol|Layer|Purpose|
|---|---|---|
|HTTP|Application|Transfers web content between browsers and servers.|
|FTP|Application|Transfers files between systems.|
|SMTP|Application|Sends email between servers.|
|TCP|Transport|Provides reliable, connection-oriented delivery, with ordered data and error recovery.|
|UDP|Transport|Provides fast, connectionless communication without guaranteed delivery.|
|IP|Network / Internet|Handles logical addressing and routes packets between networks.|

TCP vs. UDP:

- TCP: Reliability and correct ordering are priorities.
- UDP: Speed and low overhead are priorities; delivery is not guaranteed.

## 4. Transmission

Transmission is the process of sending data signals from one device to another over a communication medium.

### Transmission Types

- Analog: Uses continuous signals to represent information. Example: traditional radio broadcasts.
- Digital: Uses discrete signals (bits) to represent information. Example: modern computer networks.

### Transmission Modes

|Mode|Communication|Example|
|---|---|---|
|Simplex|One-way only.|Keyboard sending input to a computer.|
|Half-duplex|Two-way, but only one direction at a time.|Walkie-talkies.|
|Full-duplex|Two-way simultaneously.|Telephone calls.|

### Transmission Media

Transmission media are the physical or wireless means through which data signals travel.

Wired media

- Twisted Pair: Commonly used for Ethernet and LAN connections.
- Coaxial Cable: Used for cable television and some Ethernet systems.
- Fiber Optic: Transmits data using light pulses; used for high-speed connections and Internet backbones.

Wireless media

- Radio Waves: Used by Wi-Fi and cellular networks.
- Microwaves: Used in satellite communications.
- Infrared: Used for short-range communication, such as remote controls.

## Key Takeaways

- The OSI model has 7 layers; the TCP/IP model has 4 layers.
- MAC addresses identify devices at the Data Link layer; IP addresses support addressing and routing at the Network layer.
- TCP is reliable and connection-oriented; UDP is connectionless and does not guarantee delivery.
- Simplex is one-way, half-duplex is two-way but one direction at a time, and full-duplex is simultaneous two-way communication.
- Transmission can be analog or digital, and data travels through wired or wireless media.
