## 1. Main Network Components

|Component|Purpose|Examples|
|---|---|---|
|End Devices (Hosts)|Send and receive data.|Computers, smartphones, tablets, IoT devices|
|Intermediary Devices|Connect devices and networks and direct traffic.|Routers, switches, hubs, modems, access points|
|Network Media and Software|Carry data and manage network communication.|Cables, protocols, firewalls, management software|
|Servers|Provide services and resources to clients.|Web, file, mail, and database servers|

## 2. End Devices

An end device, also called a host, is a device that sends or receives data over a network.

- Generates and consumes data.
- Connects through wired Ethernet or wireless Wi-Fi.
- Examples include computers, smartphones, and smart TVs.

## 3. Intermediary Devices

Intermediary devices facilitate communication between end devices and networks. They forward data, manage traffic, and may provide security features.

### Network Interface Card (NIC)

- Hardware that enables a device to connect to a network.
- Sends and receives network data.
- Has a MAC address used for identification at the Data Link layer.
- Can be wired (Ethernet) or wireless (Wi-Fi).

### Router

- Connects different networks and forwards packets between them.
- Operates at OSI Layer 3 (Network).
- Uses IP addresses and routing tables to determine where packets should go.
- Can use routing protocols such as OSPF and BGP.
- May provide security features such as firewalls and access control lists.

### Switch

- Connects devices within the same network, typically a LAN.
- Operates at OSI Layer 2 (Data Link).
- Uses MAC addresses to forward frames to the intended destination.
- Reduces unnecessary traffic compared with a hub.

### Hub

- Connects multiple devices within a network segment.
- Operates at OSI Layer 1 (Physical).
- Broadcasts incoming data to all connected ports.
- Does not intelligently direct traffic, making it less efficient than a switch.

## 4. Network Media and Software Components

### Cabling and Connectors

Physical components that connect network devices and carry data.

- Ethernet cables: Commonly used for LAN connections.
- Fiber-optic cables: Transmit data using light and support high-speed connections.
- RJ-45 connector: Common connector used with Ethernet cables.

### Network Protocols

Protocols are standardized rules that govern how data is formatted, transmitted, received, and interpreted.

They can define:

- Data segmentation
- Addressing
- Routing
- Error checking
- Synchronization

Common examples:

|Protocol|Purpose|
|---|---|
|TCP/IP|Communication across networks and the Internet|
|HTTP/HTTPS|Web traffic|
|FTP|File transfers|
|SMTP|Email transmission|

### Network Management Software

Tools used to monitor and maintain network operations.

- Performance monitoring
- Configuration management
- Fault analysis
- Security management

### Software Firewalls

A software firewall, also called a host-based firewall, runs on an individual device and monitors incoming and outgoing traffic according to security rules.

- Helps block unauthorized connections.
- Can restrict traffic to particular applications or services.
- Protects individual devices, complementing network-level defenses.
- Example: Linux `iptables`, which can be used to filter network traffic.

## 5. Servers

A server is a computer that provides services or resources to other computers, called clients.

Common server types:

- Web server: Hosts websites and web content.
- File server: Stores and shares files.
- Mail server: Handles email services.
- Database server: Stores and manages data.

Other server functions include:

- Service provision: Hosts services clients can access.
- Resource sharing: Allows multiple users to access shared resources.
- Data management: Centralizes data storage and management.
- Authentication: Manages user access and permissions.

### Client-Server Model

In the client-server model, a client requests a service or resource, and the server processes the request and returns a response.

Example: A browser requests a webpage from a web server, which sends the webpage data back to the browser.

## Key Takeaways

- End devices generate and receive data; intermediary devices direct and manage network traffic.
- Routers connect networks using IP addresses (Layer 3); switches connect devices within a LAN using MAC addresses (Layer 2); hubs broadcast data to all ports (Layer 1).
- A NIC enables network connectivity and has a MAC address.
- Protocols define the rules for network communication.
- Software firewalls filter traffic on individual devices.
- Servers provide resources and services to clients through the client-server model.
