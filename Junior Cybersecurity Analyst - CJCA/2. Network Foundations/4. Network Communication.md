# Network Components: MAC, IP, and Ports

## 1. MAC Addresses

A Media Access Control (MAC) address is a unique identifier assigned to a device's network interface card (NIC).

- OSI Layer 2 — Data Link.
- Used to identify devices and deliver frames within a local network.
- 48 bits long, typically written as six pairs of hexadecimal digits (e.g., `00:1A:2B:3C:4D:5E`).
- First 24 bits identify the manufacturer (OUI); remaining 24 bits identify the device.
- Windows command: `getmac` displays MAC addresses for network interfaces.

### How MAC Addresses Work

- Switches use destination MAC addresses to forward frames to the correct port.
- ARP (Address Resolution Protocol) maps an IP address to its corresponding MAC address on the local network.
- When communicating with a device on the same LAN, a host uses ARP to discover the destination MAC address.

## 2. IP Addresses

An Internet Protocol (IP) address is a numerical label that identifies a device on an IP network and allows communication between networks.

- OSI Layer 3 — Network.
- Routers use IP addresses to forward packets toward their destinations.
- IP addresses can change depending on the network and its configuration, unlike MAC addresses, which are associated with network interfaces.

### IPv4 vs. IPv6

|Feature|IPv4|IPv6|
|---|---|---|
|Address length|32 bits|128 bits|
|Format|Four decimal numbers separated by dots|Eight groups of hexadecimal digits|
|Example|`192.168.1.1`|`2001:0db8:85a3:0000:0000:8a2e:0370:7334`|
|Purpose|Traditional IP addressing|Developed to address IPv4 address depletion|

## 3. Ports

A port is a number that identifies a specific service or application receiving network traffic.

- OSI Layer 4 — Transport.
- Works with TCP and UDP.
- Allows multiple services to operate on the same IP address.
- The operating system uses port numbers to direct traffic to the correct application.
- The `netstat` tool can display active connections and listening ports.

### Port Ranges

|Category|Range|Purpose|
|---|---|---|
|Well-known|0–1023|Common, standardized services|
|Registered|1024–49151|Ports registered for specific services|
|Dynamic/Private (Ephemeral)|49152–65535|Typically temporary client connections|

### Common Ports

|Port|Service|Purpose|
|---|---|---|
|20, 21|FTP|File transfer|
|80|HTTP|Web communication|
|443|HTTPS|Secure web communication|
|1433|Microsoft SQL Server|Database service|

## 4. How a Web Request Travels

When you visit a website, MAC addresses, IP addresses, and ports work together.

1. DNS Lookup: The computer resolves the domain name into an IP address.
2. Data Encapsulation: The browser creates an HTTP request. TCP carries it with a destination port (80 for HTTP or 443 for HTTPS), while the packet includes the destination IP address.
3. Local Network Delivery: ARP finds the MAC address of the default gateway (router). The computer sends the frame to that MAC address.
4. Routing: The router and intermediate routers forward the packet toward the destination IP address.
5. Server Processing: The server directs incoming traffic to the application listening on the destination port, processes the request, and generates a response.
6. Response Transmission: The response travels back to the client, targeting the client's temporary port selected by its operating system.

## Key Takeaways

- MAC address: Identifies a network interface for local network delivery — Layer 2.
- IP address: Identifies a device's network location and supports routing between networks — Layer 3.
- Port: Identifies the service or application handling traffic — Layer 4.
- ARP: Resolves local IP addresses to MAC addresses.
- DNS: Resolves domain names to IP addresses.
- `getmac`: Displays MAC addresses on Windows.
- `netstat`: Shows active connections and listening ports.

Remember: IP addresses help get packets to the right destination, MAC addresses deliver frames across the local network, and ports get traffic to the right application.
