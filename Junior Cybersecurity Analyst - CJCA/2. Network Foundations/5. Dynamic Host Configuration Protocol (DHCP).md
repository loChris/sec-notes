## 1. What Is DHCP?

DHCP (Dynamic Host Configuration Protocol) automatically configures devices with IP addresses and other network settings.

- Automatically assigns IP addresses, reducing manual configuration.
- Provides additional settings, including subnet mask, default gateway, and DNS servers.
- Helps prevent duplicate IP addresses and address conflicts.
- Recycles IP addresses when they are no longer in use.

## 2. DHCP Roles

|Role|Description|
|---|---|
|DHCP Server|Manages a pool of available IP addresses and assigns them to devices. May run on a router or dedicated server.|
|DHCP Client|A device that requests an IP address and other network configuration settings.|

## 3. How DHCP Works: DORA

The DHCP address assignment process is known as DORA.

## D

Discover

The client broadcasts a DHCP Discover message to locate available DHCP servers.

## O

Offer

A DHCP server responds with a DHCP Offer proposing an IP address lease.

## R

Request

The client sends a DHCP Request indicating that it accepts the offered IP address.

## A

Acknowledge

The server sends a DHCP Acknowledge confirming the assignment. The client can now use the IP address.

## 4. DHCP Lease and Renewal

An IP address assigned by DHCP is generally provided for a limited period called a lease.

- The lease determines how long the client can use the assigned IP address.
- Before the lease expires, the client attempts to renew it by sending a DHCP Request.
- If the server approves the renewal, it responds with a DHCP Acknowledge.
- Renewing the lease allows the client to continue using the IP address.

Example: A smartphone receives an IP address with a 24-hour lease. Before the lease expires, it requests a renewal from the DHCP server.

## 5. Example: Assigning an IP Address

Alice connects her new laptop to the office network.

1. Discover: The laptop searches for a DHCP server.
2. Offer: The server offers `192.168.1.10`.
3. Request: The laptop requests the offered address.
4. Acknowledge: The server confirms the assignment.

The laptop can now communicate on the network using `192.168.1.10`. Before its lease expires, it must request renewal to continue using the address.

## Key Takeaways

- DHCP automates IP address and network configuration.
- DORA stands for Discover, Offer, Request, Acknowledge.
- The server assigns addresses; the client requests them.
- A lease determines how long an assigned IP address can be used.
- Clients can renew leases before they expire.
