## Private vs. Public IP Addresses

- Public IP addresses: Globally unique addresses assigned by ISPs that allow devices and networks to communicate over the internet.
- Private IP addresses: Used within local networks, such as homes, schools, and offices. They are not directly routable over the public internet.

Common private IPv4 ranges:

- `10.0.0.0 – 10.255.255.255`
- `172.16.0.0 – 172.31.255.255`
- `192.168.0.0 – 192.168.255.255`

NAT allows devices using private IP addresses to access the internet while sharing public IP addresses, helping conserve the limited IPv4 address space.

## What is NAT?

Network Address Translation (NAT) is a process performed by a router or similar device that modifies the source or destination IP addresses in IP packet headers as they pass through.

## How NAT Works

1. A device sends a request using its private IP address.
2. The router replaces the private source IP with its public IP address.
3. The request travels across the internet to its destination.
4. The response returns to the router's public IP.
5. The router checks its NAT table, translates the address information, and forwards the response to the correct internal device.

Port numbers help the router distinguish connections when multiple devices share the same public IP.

## Types of NAT

- Static NAT: Maps one private IP address to one public IP address.
- Dynamic NAT: Assigns a public IP address from an available pool when needed.
- Port Address Translation (PAT): Allows multiple devices to share one public IP address by distinguishing their connections using port numbers. This is common in home and small office networks.

## Benefits and Trade-Offs

Benefits

- Conserves IPv4 addresses.
- Provides a basic layer of security by limiting direct exposure of internal network addresses.
- Allows flexible internal IP addressing.

Trade-offs

- Hosting public servers may require additional configuration, such as port forwarding.
- Some protocols require special handling to work through NAT.
- Can complicate network troubleshooting.

## Key Takeaway

NAT allows private networks to communicate with the internet by translating IP addresses. PAT is the most common type for home networks because multiple devices can share a single public IP address.
