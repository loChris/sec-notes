## What is DNS?

The Domain Name System (DNS) acts like the internet's phonebook. It translates human-readable domain names, such as `www.google.com`, into IP addresses that computers use to locate online resources.

- Domain Name: A readable address, such as `www.example.com`.
- IP Address: A numerical address, such as `93.184.216.34`.

## DNS Hierarchy

DNS is organized in a tree-like structure:

- Root Servers: At the top of the DNS hierarchy.
- Top-Level Domains (TLDs): Extensions such as `.com`, `.org`, and `.net`.
- Second-Level Domains: The name registered under a TLD, such as `example` in `example.com`.
- Subdomains / Hostnames: Names such as `www` in `www.example.com` or `accounts` in `accounts.google.com`.

## DNS Resolution Process

When you enter a domain name into your browser, DNS resolution finds its corresponding IP address.

1. You enter a domain name, such as `www.example.com`.
2. Your computer checks its local DNS cache for the IP address.
3. If it isn't cached, your computer queries a recursive DNS server.
4. The recursive server queries a root server to find the appropriate TLD name server.
5. The TLD server directs it to the domain's authoritative name server.
6. The authoritative server provides the IP address.
7. The recursive server returns the IP address to your computer, allowing it to connect to the website.

This process typically happens in fractions of a second.

## Key Takeaway

DNS translates domain names into IP addresses so users can access websites without memorizing numerical addresses. Its hierarchical structure helps DNS servers locate the correct address efficiently.
