Internet architecture describes how data is organized, transmitted, and managed across networks. Different architectures offer different trade-offs in scalability, performance, security, and management.
## Types of Network Architecture
### 1. Peer-to-Peer (P2P)
Each device acts as both a client and a server, sharing resources directly without requiring a central server to host the data.
- Advantages: Scalable, resilient, and distributes resource costs.
- Disadvantages: More difficult to manage and secure; resources may become unavailable when peers disconnect.
- Examples: BitTorrent and file-sharing networks.
### 2. Client-Server
Clients send requests to centralized servers, which process them and return the requested data or services.

Tier models:
- Single-Tier: Client, server, and database reside on the same machine.
- Two-Tier: Client communicates directly with a server.
- Three-Tier: Separates the presentation layer, application logic, and database into three tiers.
- N-Tier: Uses additional tiers to separate responsibilities and support complex applications.
- Advantages: Centralized management, security policies, and optimized server performance.
- Disadvantages: Potential single point of failure, high maintenance costs, and network congestion.
### 3. Hybrid Architecture
Combines client-server and P2P models. Central servers handle tasks such as authentication and coordination, while peers may transfer data directly.
- Advantages: Reduces server workload while retaining centralized control.
- Disadvantages: More complex to implement; central server failures can disrupt coordination.
- Example: Video conferencing applications.
### 4. Cloud Architecture
Uses third-party providers, such as AWS, Azure, and Google Cloud, to provide computing resources and services over the internet.

Five essential characteristics:
- On-demand self-service
- Broad network access
- Resource pooling
- Rapid elasticity
- Measured service (pay for resources used)

- Advantages: Scalability, reduced hardware maintenance, and flexibility.
- Disadvantages: Vendor lock-in, security and compliance concerns, and reliance on internet connectivity.
- Examples: Google Drive and Dropbox.

### 5. Software-Defined Networking (SDN)
Separates the control plane, which decides where traffic goes, from the data plane, which forwards traffic. A software-based controller manages network behavior.
- Advantages: Centralized control, automation, scalability, and efficient traffic management.
- Disadvantages: Controller vulnerabilities, implementation complexity, and specialized skill requirements.
- Examples: Datacenters and large enterprise networks.
## Key Comparisons

| Architecture  | Main characteristic                                 | Common uses                      |
| ------------- | --------------------------------------------------- | -------------------------------- |
| P2P           | Devices share resources directly                    | File sharing, blockchain         |
| Client-Server | Centralized servers provide services                | Websites, email                  |
| Hybrid        | Combines centralized control and peer communication | Messaging, video conferencing    |
| Cloud         | Provider-managed computing resources                | Cloud storage, SaaS, PaaS        |
| SDN           | Software-based centralized network control          | Datacenters, enterprise networks |
## Key Takeaway
Different network architectures solve different problems. P2P distributes resources, client-server centralizes services, hybrid combines both, cloud provides on-demand computing resources, and SDN makes network management programmable. Organizations often combine these approaches to balance performance, scalability, cost, and security.
